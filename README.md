# RAG-Based-Academic-Assistant-for-Indian-University-Syllabi
Citation-grounded RAG assistant for Indian university syllabi. Answers student questions only from approved syllabus, notes and PYQs, cites document/unit/page, and refuses when the answer isn't in the sources. Hybrid retrieval, PYQ analytics, quiz generation. FastAPI + React + Gemini. GLA University major project (G62).
